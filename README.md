## 🛠️ Problem Statement 1: Technical Assessment

### Question 1: API Data Retrieval and Storage
> **Task**: Fetch data from an external REST API providing a list of books in JSON format (title, author, publication year), store it in a local SQLite database, and display the retrieved data.

- **Implementation**: [`question1/question_1.py`](question1/question_1.py)
- **API Endpoint**: Open Library REST API (`https://openlibrary.org/search.json?q=harry+potter`)
- **Database**: SQLite (`question1/books_data.db`)
- **Schema**:
  ```sql
  CREATE TABLE IF NOT EXISTS books (
      id TEXT PRIMARY KEY,
      title TEXT,
      author TEXT,
      year TEXT
  );
  ```
- **Execution**:
  ```bash
  python question1/question_1.py
  ```
- **Output Sample**:
  ```text
  Fetching books from: https://openlibrary.org/search.json?q=harry+potter...
  Retrieved 100 books from API.

  --- Stored Books in SQLite Database ---

  ID:     /works/OL82537W
  ```

### Question 2: Data Processing and Visualization
> **Task**: Given a dataset containing students' test scores, fetch data from an API, calculate the average score, and create a bar chart to visualize the data.

This solution is divided into a production-grade backend service and an analytical client:
1. **Backend Server ([`question2/server.py`](question2/server.py))**: Built using **FastAPI** & **Uvicorn**, providing the `/api/students/` endpoint.
2. **Client Script ([`question2/question_2.py`](question2/question_2.py))**: Requests student records, calculates statistical metrics, and generates a bar chart with an average benchmark line using **Matplotlib**.

#### Execution Steps:

**Step 1: Start the FastAPI Backend**
```bash
python question2/server.py
```
*(Interactive API documentation is accessible at `http://127.0.0.1:8000/docs`)*

**Step 2: Run the Client Analytics & Plotting Script**
```bash
python question2/question_2.py
```

#### Metrics & Output:
- **Total Students Evaluated**: 7
- **Average Score**: **87.6**
- **Visualization Artifact**: [`question2/student_scores.png`](question2/student_scores.png)
